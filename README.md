# sshDesktop

> 版本：未设版本 · 更新时间：2026-10-20 16:30 +08:00 · 状态：设计阶段，尚无可运行的代码

sshDesktop 是一个装在 Linux 服务器上的开源 Web 管理面板，结合了 [1Panel](https://github.com/1Panel-dev/1Panel) 的主机管理能力和[哪吒探针](https://github.com/nezhahq/nezha)的多机监控能力。除了传统的后台界面，它还提供**桌面模式**：在浏览器里渲染一个 Windows 11 风格的桌面，有任务栏、开始菜单、可拖拽的窗口和文件资源管理器，让你用操作 PC 的方式管理服务器。

## 规划中的功能

| 阶段 | 功能 |
| --- | --- |
| 首版 | 监控（实时与历史）、文件资源管理器、多窗口终端、进程与系统服务、Docker 与 Compose、应用商店、网站管理与自动证书、防火墙、SSH 设置、计划任务、备份恢复、服务监控、按月流量统计、多服务器批量命令、账号与功能权限、操作审计 |
| 第二阶段 | Fail2ban 等安全工具、AI 助手、通行密钥登录、macOS 风格 |
| 以后 | 告警推送、数据库管理、公开状态页、DDNS |

首版按 4 个里程碑交付：单机桌面 → 多服务器 → 容器与应用 → 网站与安全。

## 架构要点

- **面板**（`sshdesktop`）：以 root 运行，管理本机全部功能；同时可作为中心面板，通过 SSH 对其他服务器做监控、文件、终端和批量命令等轻量操作。
- **agent**（`sshdesktop-agent`）：只读的轻量监控程序，只监听本机 Unix socket，可被多个面板通过 SSH 读取；装了面板的服务器自带 agent 能力。
- **访问方式**：默认端口 33333。未配置域名和 HTTPS 时只接受本机连接，通过 SSH 隧道访问；配置后才对公网开放。
- **技术栈**：后端 Go，前端 Vue 3 + TypeScript，数据库 SQLite，单个二进制部署。
